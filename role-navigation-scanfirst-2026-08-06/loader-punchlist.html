The same tags pivoted Bin → Category → missing. Its whole purpose is to answer "what's left and where do I walk?" in one screen, so every category header carries a walk-to hint — and where the location genuinely isn't known, it renders TBD rather than inventing one.

"Missing" is every tag not yet Loaded — which includes Scanned (in hand, not on the truck yet), Not scanned, Short, and Pending — backfill. Cloud tags get their own bucket because their category, and therefore their walk-to, is unknown. Every row carries its sub-order chip so you know which part of the bin to walk to.

Complete loading
The loader completes the loading, not the delivery. ON_TRUCK is the loader's terminal state; DELIVERED is the driver's.
Locked decisions visible on this screen Walk-to hints, with honest TBDs. Rebar and Tendon have real destinations; Hardware and Lumber locations are genuinely unknown, so they render TBD instead of a plausible-looking invention. Pending — backfill reads "area unknown."
Terminology (§15.2). The button is "Complete loading", not "Complete delivery run" and not "Depart." The event registry separates LOADED (per tag) from a proposed LOADING_COMPLETED (per run), and DELIVERED stays the driver's. My draft last night said "Depart short" — that was office/driver language the locked spec had already rejected, and it is corrected here.
Per-row status is kept here and removed on the in-progress view. The rule (§15.1) is that the label is dropped only where rows are grouped by status; this view groups by category, with statuses deliberately mixed inside each group, so the corner dot is the only thing distinguishing Staged from At-machine from Not-printed.
Unbacked: the whole punch list needs the category field on the tag (L12), which is also GA-WIP-192's prerequisite — one fix serves both. Walk-to locations need a physical-location field (G10).
Open conflict between two prior artifacts, not introduced here: LEAN renders cloud tags as HPT Cloud · f3a1…, but the GA-WIP-179 spec says label them "HPT Cloud tag — details pending" and explicitly not a truncated GUID. I have used the GA-WIP-179 wording here. Flagging it so you can settle which one wins.
