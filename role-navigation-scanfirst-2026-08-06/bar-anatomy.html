Role tabs
Up to 3 tabs inline, the rest behind +N. The 2026-08-05 dropdown is retained only as that overflow. A single-function worker gets no tabs at all — the strip is then just the identity chip.
Cross-role pills
Icon + count only, no label. Zero count = zero width: max-width, padding, margin, opacity and border-width all animate to 0 over 220 ms. Not greyed — gone.
Identity chip
(Function, Authority) compressed to badge + authority letter. The function half is already shown by the active tab, so only the authority is spelled out. Tapping it is the authority swap — the old Supervise OFF/ON row is deleted.
What is NOT in the bar
No page title, no logo, no hamburger, no back arrow, no breadcrumb, no notification bell. Scan is the root; there is nothing to go back to.

How these were measured Box-model arithmetic on each set's _shared.css — padding + line-box + borders + bottom margin per row — not a rendered screenshot, so treat them as ±3 px design targets, not measurements off a device. The URL bar is a mockup device hint and is excluded from both columns. On a 390×780 phone frame, 102 px is roughly 13% of the viewport, or about 40% of the camera viewport's height.

Why this one The audit found five overlapping status vocabularies live in production (fab_status; the loader category set; the 6-stage lifecycle; the ClickUp WIP phase pill; and the derived tag status). Nothing can "feel the same" across roles until one wins. The 6-stage lifecycle is already the locked cross-surface answer for Bins, the loader's WIP_LOADER_LIFECYCLE_V2 view, and the supervisor+lead mockup, so every screen in this set uses it and nothing else — in the strip, in the roster subs, in the punch list, in the pills.
Precondition: the phase→stage map is currently mirrored in three files that must stay byte-identical. Standardising on it without collapsing that duplication first multiplies the risk.

Open decisions this set takes a position on

Audit questionPosition taken here
§9.3 — the .val slot carries percent, fraction and severity Percent only, with a small unit caption. Severity moves to a .pill and the row's left border. Counts render as plain integers in a fraction context, never in .val.
§9.4 — five status vocabularies 6-stage lifecycle everywhere. No screen in this set uses the other four.
Q2 — is a worker↔work assignment model in scope? Sidestepped, not assumed. Every "my assigned X" is re-worded to something derivable today — "bins I touched today" (from events.actor) rather than "assigned bins".
Q4 — presence on the supervisor roster Dropped. No clock-in signal exists and the locked spec records "no software OOO handling". The header counts assignment, not attendance.
Spec §9.1 vs locked-single-role.html — badge at zero Spec wins, harder. Zero hides the pill and reclaims its width; the entry stays reachable behind the tab overflow.
U1 / P1 — function vs station Independent axes. Station is not in the bar; it renders as the where line of the context strip, because that is what it is. Still needs James's ruling.
