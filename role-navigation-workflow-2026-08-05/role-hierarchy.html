Portfolio view across all functions · sees discrepancies, KPIs, and safety incidents in one surface

Assignment rules

A user record carries an assigned_functions[] array and an authority level. If len(assigned_functions) == 1 and locked_to_primary = true, the top-nav function dropdown is hidden. Cross-role widgets (Inventory + Maintenance) are always in nav, for every authority level.

Landing rule

Landing route = primary function's home. Function swaps and authority swaps never re-auth and preserve session. Every write logs (home_function, acting_function, authority).

What's not in the matrix

Executive is a portfolio surface, not a function. Auditor is read-only across every function; that's the third column intent. Any operator can be promoted temporarily to Supervisor for a shift via the same Supervise: ON toggle — the change is per-session, not stored on the user record.
