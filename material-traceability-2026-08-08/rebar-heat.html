Updated 2026-08-08: James's mapping accepts Serial or direct Heat — a rebar bundle may be tagged either way, and the serial links to the heat. Earlier drafts demanded a heat only, following CertProcessor's cert-completeness rule (_System/enforce_completeness_gate.py:63-66), which answers a different question (spec §2.1).

Either one satisfies the gate. A captured serial is resolved to its heat later, at verification — index row → ParentItemId → the parent cert's HeatNumber (spec §2.4). The worker is never asked for both.

Only the first sequence step is gated. tagstore.py:32 defines operations PK = (tag_id, seq) as “a tag's fab routing”, and derive_operations() makes seq 1 = SHEAR for every tag (tagstore.py:1055-1069). Frame C is the same tag at seq 2: the heat is shown, never re-asked (§4.3).

Grounding — and what has no data behind it Real, in code today: the operations (tag_id, seq) routing model (tagstore.py:32), derive_operations() returning seq 1 = SHEAR and seq 2 = BENDER (tagstore.py:1055-1069), get_operations() ordered by seq (tagstore.py:2602), work_center_for() resolving the picker's station string to a work centre (scan_events.py:70-86), and the OP_FINISHED per-station dedup block the gate rides along on (function_app.py:1462-1511) — which already fetches the tag's prior events, so the gate costs no extra query.
From James, 2026-08-08 (authoritative for capture): Rebar → Serial (links to heat) OR direct Heat. From CertProcessor (cert completeness): Rebar requires HeatNumber (:63-66), and SERIAL_REQUIRED does not include Rebar (pipeline_constants.py:79-82) — so a serial-only capture meets the cert rule only through the §2.4 resolution. That indirection needs no new data: index rows already carry ParentItemId. A serial resolving to no parent, or to a parent with an empty HeatNumber, is unmatched — the chain is genuinely broken there.
No heat, lot or batch field exists anywhere in WIP Processor today. There is no tag_cert_link table, no capture UI, and no integration of any kind with CertProcessor. Every value on these frames is invented.
“Reuse last” is drawn as the biggest target on purpose. A worker cutting 40 bars from one bundle will not retype a heat 40 times — if reuse is small, the gate gets defeated by mistyping instead. capture_method is recorded so a station running 95% reused is visible before an auditor finds it (§7.1).
