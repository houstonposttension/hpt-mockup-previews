Design notes
Step bar: 3 steps — Setup → In Progress → End Run. Step 1 active.
Line grid: big tap targets, real-time line status (Running/Paused/Idle). EXT-2 pre-selected.
Product preview: shows die size, target cycle, temp setpoint from master data once a product is chosen — confirms operator picked the right config before starting.
Target cycles: operator sets goal; footage auto-calculates. Gives supervisor a completion estimate on the real-time view.
Start notes: free-text for lot numbers / setup issues; carries into run record.
