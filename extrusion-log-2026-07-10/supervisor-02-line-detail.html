Design notes
Hourly bar chart: cycles per hour for the current shift on this line. Gaps = idle (no run). Color = on-target vs below. Production: clickable bar → run detail.
Temp log: bar-chart style row — length proportional to temp vs setpoint. Out-of-spec row (12:00, 186 °C) gets amber border + flag glyph.
Alert timeline: chronological event feed — starts / cycle drift / temp spikes / run end. No separate "notifications" screen needed.
Scrap log: timestamped with operator-supplied reason from screen 3 cycle tap or end-of-run form.
Operator switches: tracks who was on the line and when — important for ISO 9001 traceability.
